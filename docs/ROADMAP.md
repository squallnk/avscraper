- **不做 115 直连**。任何 115 SDK / Cookie 都不进这个进程。

- **不做文件归档**。整理交给 Symedia；`Organizer` 只在显式打开且模板指向自己目录时使用。
- **不做任务图 / 链式依赖**。当前规模用不上，加了就是 bug 来源。
